# Cassi Kelly — Portfólio profissional

Site estático responsivo, desenvolvido em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Publicação

1. Crie um repositório no GitHub (por exemplo, `cassi-kelly-site`).
2. Envie **os arquivos desta pasta para a raiz** do repositório, incluindo `index.html`, `retrato-cassi-kelly.jpg`, `favicon.svg` e `.nojekyll`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
4. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## Conteúdo

- Apresentação pessoal e fotografia original do HTML fornecido
- História, projetos e trajetória
- Links para SuperPrompt e GitHub
- Contato por WhatsApp e e-mail
- SEO básico, responsividade e navegação acessível

## Personalização

Edite os textos, links e estilos no `index.html`. A imagem está separada no arquivo `retrato-cassi-kelly.jpg` para facilitar manutenção. Não são necessários pacotes, compilação ou chaves de API.

**Nota:** o projeto SuperPrompt é acessado por link externo; ele não está embutido neste portfólio. Confira se os links dos projetos estão ativos após publicar.
